🔗 Sincronizar celulares

Sincronizado em tempo real ✅

Pra conectar o outro celular, envie a configuração abaixo pra ele colar aqui também (é só uma vez).

Sem sincronização, os dados ficam só neste aparelho. Pra pontos e tarefas aparecerem iguais no celular dela e no seu, conecte os dois a um banco gratuito (Firebase).

  1. Acesse console.firebase.google.com e crie um projeto grátis (sem cartão).
  2. No menu, vá em Build → Realtime Database → Criar banco de dados → modo teste.
  3. Clique na engrenagem ⚙️ → Configurações do projeto → role até "Seus apps" → ícone </> (Web) → registre o app.
  4. Copie o objeto firebaseConfig que aparece (o bloco com apiKey, authDomain etc).
  5. Cole ele aqui em cima e toque em Conectar. Depois é só mandar essa mesma configuração pro celular dela.
